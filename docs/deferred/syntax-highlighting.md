# Syntax highlighting and language detection

Syntax highlighting is something I definitely want in a future release, I
tried a basic system with the language guessed from the
filename first,content second, named in the status bar, and
overridable from a searchable list of everything the installed GtkSourceView
knows. It's not perfect yet though, so until then it is on the back burner.

GtkSourceView itself is staying either way. The line numbers, the undo stack,
bracket matching and the find bar's search all come from it, and it will be
there when needed when I want to give this a proper bash.
